# gamas
## Eaglercrafting

Extension for my other repo that provides the Eaglercraft files.

### Installation for dummies
  1. Create a folder in the codespace (in the root folder)
```
> mkdir Eaglercraft
```
  2. CD into the new folder and pull this repo
```
> cd Eaglercraft
> git clone https://github.com/5wjbdm9y75-max/gamas.git
```
  3. Unzip every zip file inside that folder and rm the remnants
```
> ls Eaglercraft
  blah blah blah.zip

> unzip blah blah blah.zip
  /blah/blah/nriuer.wasm
  /oeifjoiseh/weighweg.html

> rm blah blah blah.zip
```
  4. You should be done, but if anything fails to clone or unzip, delete it; I'm probably testing different versions
